2 Concepto: be going to para planes

Para hablar de un plan que ya decidiste se usa am / is / are + going to + verbo base. Es como el español «voy a…».

Ejemplo
Afirmativo I'm going to learn Python. She's going to apply.
Negativo I'm not going to work tomorrow. They aren't going to travel.
Pregunta Are you going to take the course?
Respuesta Yes, I am. / No, I'm not.
Wh- What are you going to do next year?

💡 Al hablar rápido, going to suena «gonna»: I'm gonna study. Úsalo al hablar, pero escribe siempre going to.

Expresiones de futuro

Expresión Significa
tomorrow mañana
this weekend / this Friday este fin de semana / este viernes
next week / month / year la próxima semana / el próximo mes / año (sin the)
in two months dentro de dos meses (≠ two months ago)
soon pronto

⚠️ «Dentro de un mes» es in a month, no «after a month». Y como con last, next va sin artículo: next year.

Ejemplos

  • I'm going to finish my degree next year.Voy a terminar mi carrera el próximo año.
  • We're going to present the dashboard on Friday.Vamos a presentar el dashboard el viernes.
  • She's going to move to Lima in two months.Ella se va a mudar a Lima dentro de dos meses.
  • I'm not going to work this weekend.No voy a trabajar este fin de semana.

I'm also going to improve my technical skills. I'm going to take a Python course in January, and I'm going to build two projects for my portfolio.
