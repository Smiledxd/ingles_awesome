2 Concepto: Power BI en inglés

En Power BI casi todo el vocabulario es en inglés, incluso si usas la interfaz en español. Esta es la ruta de trabajo típica:

Paso Vocabulario
1. Get data
conectar las fuentes		 source, connect, import
2. Transform
limpiar en Power Query		 remove columns, change type, merge
3. Model
unir tablas y crear cálculos		 data model, relationship, measure, DAX
4. Visualize
armar las páginas del reporte		 visual, card, slicer, filter
5. Publish
compartir y actualizar		 publish, workspace, refresh

Palabras clave

Inglés Qué es
report / dashboard el reporte (varias páginas) / el tablero de una página
visual cada gráfico, tabla o tarjeta
card visual que muestra un solo número (KPI)
slicer filtro visual en la página (por región, fecha…)
measure cálculo en DAX, como Total Sales
calculated column columna nueva calculada fila por fila
relationship (one-to-many) la unión entre dos tablas (uno a muchos)
fact table / dimension table tabla de hechos (ventas) / de dimensión (productos)
refresh actualizar los datos

5 Lectura corta

La documentación corta de un dashboard, para los usuarios de la empresa. Léelo primero sin audio, luego escúchalo y responde las preguntas.

Sales dashboard: how it works

This report helps managers follow sales every day. It has three pages: Overview, Products and Stores.

Data: the dataset connects to the company's SQL database. It refreshes every day at 7 a.m., so the numbers show the sales until the previous night.

Model: Sales is the fact table. It has one-to-many relationships with three dimension tables: Date, Product and Store.

Measures: Total Sales, Orders, Average Order Value and Growth vs. Last Year. All the measures are in a folder called _Measures.

How to use it: use the slicers at the top to filter by date and region. Hover over a visual to see the tooltip with more details.
