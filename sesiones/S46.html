Un script corto… y un error

import pandas as pd

sales = pd.read_csv("sales.csv")
stores = pd.read_csv("stores.csv")

df = sales.merge(stores, on="store_id", how="left")
df["amount"] = df["amount"].fillna(0)

print(df.groupby("Region")["amount"].sum())
Traceback (most recent call last):
  File "report.py", line 9, in <module>
    print(df.groupby("Region")["amount"].sum())
KeyError: 'Region'
  • This script reads two CSV files and merges them on store_id.Este script lee dos archivos CSV y los combina por store_id.
  • Then it fills the missing amounts with zero.Luego rellena los montos faltantes con cero.
  • I got a KeyError. The error message said 'Region'.Me salió un KeyError. El mensaje de error decía 'Region'.
  • It turned out that the column name was lowercase: 'region'.Resultó que el nombre de la columna estaba en minúsculas: 'region'.
  • I fixed it by changing 'Region' to 'region'.Lo arreglé cambiando 'Region' por 'region'. (by + -ing)

Errores comunes y qué significan

Error Significa…
KeyError la columna o clave no existe (revisa el nombre)
NameError usaste una variable que no está definida
TypeError tipo de dato equivocado (por ejemplo, texto + número)
ValueError el valor no es válido para esa operación
FileNotFound­Error el archivo no existe en esa ruta

💡 Estructura para explicar un error en una entrevista: qué pasó (I got a…) → qué decía (The error message said…) → la causa (It turned out that…) → la solución (I fixed it by + -ing) → qué aprendiste.

5 Lectura corta

Carla escribe en su blog sobre un error que le costó dos horas. Léelo primero sin audio, luego escúchalo y responde las preguntas.

The bug that took me two hours

Last week, I wrote a short Python script to merge our sales data with the store list. It looked perfect, but the total sales were 30% higher than in Excel.

There was no error message, so I started checking step by step. First, I counted the rows before and after the merge. Before: 5,000 rows. After: 6,500 rows!

It turned out that the store list had duplicate store IDs. The merge matched some sales twice.

I fixed it by removing the duplicates with drop_duplicates() before the merge. Now the totals match.

Lesson learned: always check the number of rows after a merge.
