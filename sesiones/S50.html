2 Concepto: ¿cuál uso?

En español a veces da igual decir «usé» o «he usado». En inglés no: la regla depende de si dices cuándo.

Pasado simple: un momento terminado y concreto

Si dices o preguntas cuándo (yesterday, last year, in 2024, two months ago, when I was…), usa pasado simple.

  • I learned Excel at university in 2024.Aprendí Excel en la universidad en 2024.
  • I started with Power BI last semester.Empecé con Power BI el ciclo pasado.
  • When did you learn SQL? — I learned it last year.¿Cuándo aprendiste SQL? — Lo aprendí el año pasado.

Presente perfecto: sin fecha, o hasta ahora

Si no dices cuándo, o la acción llega hasta hoy (ever, never, for, since, so far, this year, yet), usa presente perfecto.

  • I've used Excel for three years.He usado Excel durante tres años. (y sigo)
  • I've built two dashboards so far.He construido dos dashboards hasta ahora.
  • Have you ever used Python? — No, I haven't.¿Alguna vez has usado Python? — No.

El truco de la entrevista: abre con presente perfecto, da detalles en pasado

  • I've used SQL in three projects. In the last one, I wrote queries for a sales report.He usado SQL en tres proyectos. En el último, escribí consultas para un reporte de ventas.
  • I've worked with Power BI since June. I started with a free course.He trabajado con Power BI desde junio. Empecé con un curso gratuito.

Los 3 errores típicos

❌ Error ✅ Correcto
I have used Excel in 2024. I used Excel in 2024.
I use Excel since 2024. I've used Excel since 2024.
I have learned SQL two years ago. I learned SQL two years ago.

I've worked with Excel for four years. I learned it in my first year at university, and I've used it in almost every course since then. I'm comfortable with pivot tables and XLOOKUP.

I started with SQL last year. I took an online course in March, and in June I used SQL for the first time in a real project: a sales report for a small store in Miraflores.

I've also used Power BI, but only for about three months, so my level is basic. I haven't used Python in a project yet, but I've recently started a course.

So far, SQL has been my favorite tool.
