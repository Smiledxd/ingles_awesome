2 Concepto: SQL en inglés

SQL ya está en inglés: SELECT, WHERE, GROUP BY. El reto es explicar una consulta con frases completas. Se pronuncia «es-kiú-el» o «síkuel»; las dos formas son correctas.

Vocabulario de bases de datos

Inglés Qué es

foreign key columna que apunta a la clave de otra tabla

Explicar una consulta, cláusula por cláusula

SELECT c.region,
       COUNT(*) AS orders,
       SUM(o.amount) AS total_sales
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
WHERE o.order_date >= '2026-01-01'
GROUP BY c.region
ORDER BY total_sales DESC;
Cláusula Cómo lo explicas
SELECT It selects the region, the number of orders and the total sales.
FROM … JOIN … ON It joins the orders table with the customers table on customer_id.
WHERE It filters the rows: only orders from 2026.
GROUP BY It groups the results by region.
ORDER BY … DESC It sorts the results by total sales, from highest to lowest.

Escucha la explicación completa.

💡 En resumen: The query returns one row per region, with the orders and total sales. Termina siempre diciendo qué devuelve.

5 Lectura corta

Un fragmento de la guía interna de SQL de una empresa para practicantes. Léelo primero sin audio, luego escúchalo y responde las preguntas.

SQL tips for new interns

Before you write a query, look at the tables. Check the primary key of each table and the foreign keys that connect them.

Use JOIN carefully. An INNER JOIN returns only the rows with a match in both tables. A LEFT JOIN returns all the rows from the left table, even without a match; the missing values appear as NULL.

Always filter early with WHERE, especially in big tables. It makes your queries faster.

When you use GROUP BY, every column in SELECT needs to be in the GROUP BY or inside an aggregate function like SUM or COUNT.

Finally, give your columns clear names with AS, for example total_sales.

SELECT product_name, AVG(price) AS avg_price
FROM products
WHERE category = 'Laptops'
GROUP BY product_name
HAVING AVG(price) > 1000
ORDER BY avg_price;
