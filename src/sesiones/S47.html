2 Concepto: la estructura de la documentación

Cuando no sabes cómo funciona algo, la respuesta está en la documentación (docs), y casi siempre está en inglés. La buena noticia: todas siguen la misma estructura.

Sección Qué te dice
Signature
 el nombre de la función y sus parámetros: fillna(value=None, inplace=False)
Description
 una frase con lo que hace
Parameters
 qué le puedes pasar, de qué tipo y su valor por defecto
Returns
 qué devuelve
Raises
 qué errores puede lanzar
Examples
 código de ejemplo (¡empieza por aquí!)
See also
 funciones relacionadas

Palabras que se repiten en toda documentación

  • optional / requiredopcional / obligatorio
  • default: 'first'valor por defecto: 'first' (si no pones nada, usa ese)
  • If True, the function modifies the original DataFrame.Si es True, la función modifica el DataFrame original.
  • It returns a new DataFrame.Devuelve un DataFrame nuevo.
  • It raises a KeyError if the column does not exist.Lanza un KeyError si la columna no existe.
  • This parameter is deprecated.Este parámetro está obsoleto (se va a eliminar).

💡 Truco: lee primero la descripción y los ejemplos. Después ve a Parameters solo para el parámetro que necesitas. No hace falta leer todo.

Una página de documentación simplificada (redactada para el curso) de una función de pandas. Léelo primero sin audio, luego escúchalo y responde las preguntas.

drop_duplicates (simplified docs)

DataFrame.drop_duplicates(subset=None, keep="first")

Remove duplicate rows from a DataFrame.

Parameters — subset: column name or list of column names, optional. Only these columns are used to find duplicates. By default, it uses all the columns. keep: "first", "last" or False, default "first". "first" keeps the first row of each group of duplicates, "last" keeps the last one, and False removes all of them.

Returns — DataFrame: a new DataFrame without the duplicate rows. The original DataFrame does not change.

Example — df.drop_duplicates(subset=["store_id"]) keeps one row for each store ID.

See also — DataFrame.duplicated: returns True or False for each row.
